NOIR PWA v2 — 黒×赤アップデート

追加機能:
- 予定日の指定、今日/今後/すべての表示切り替え
- タスクの編集、削除、完了チェック
- 完了率のバー
- JSONバックアップの保存・復元
- 最優先タスク3件の表示（今日の未完了のみ）

既存データ:
- 前バージョンと同じlocalStorageキー(noir_tasks_v2)を使います。
- 日付のない旧タスクは、初めて新バージョンを開いた日の予定として表示します。
- 既存データは同じ端末・同じホーム画面アプリの保存領域でのみ引き継がれます。
- 万一に備え、旧版のデータを保存したい場合はブラウザのデータを消さないでください。
- iPhoneとPC間のデータ同期はありません。

GitHubで更新:
1. このZIPを展開。
2. GitHubのnoir-app → Add file → Upload files。
3. iconsフォルダを含む中身をアップロード。既存ファイルは同名で上書きされます。
4. Commit changes。GitHub Pagesの更新が反映されたらNOIRを再起動。
5. 古い画面のままならアプリを完全に終了し、Safariで公開URLを再読み込み。

注意: PWAなのでiPhoneのロック画面ウィジェットはありません。
