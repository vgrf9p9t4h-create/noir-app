NOIR V6 - iPhoneショートカット連携

「ショートカットで壁紙を変更」ボタンから現在の壁紙画像をiOS共有シートに送ります。iPhoneショートカットアプリで「共有シートに表示」を有効にした画像受け取りショートカットを作成し、「壁紙を設定」アクションを追加してください。共有メニューからそのショートカットを選択すると壁紙変更に進めます。

重要：iOSのセキュリティ制約により、Web版NOIRから壁紙を直接変更する真のワンタップ機能は実現できません。共有メニューでショートカットを選ぶ操作が必要です。iOSのバージョンや設定により確認が表示される場合があります。

V5の全機能・データ保存キーは維持しています。GitHub更新前にバックアップを保存してください。ZIPを展開し中身をリポジトリのルートにアップロードしてください。
